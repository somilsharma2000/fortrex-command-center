# Social Connections, Analytics & Automations

## Connection options
| Channel | Mode | What it unlocks | Requirement |
|---------|------|-----------------|-------------|
| Instagram Business | API | Publishing, stories, Insights (reach, impressions, follower growth, engagement) | IG Business/Creator account linked to a Facebook Page |
| X / Twitter | Manual | Content batches committed here; you post. No API available. | — |
| LinkedIn | API | Company page posting + page analytics | Admin access to the page |
| Facebook Pages | API | Page publishing + page metrics | Page admin |
| TikTok | API | Video publishing + video metrics | TikTok account |
| Discord | API | Community channel ops, invites | Discord account |

## Analytics cadence
- Weekly report every Friday: pulled from all connected channels, committed to `analytics/`, and the Command Center page is updated.
- Per-post tracking for countdown-phase content: what earned saves/shares vs what did not.

## Automation schedule
1. **Weekly Content Batch — Mondays.** Phase-aligned batch (posts, stories, captions, hashtags) committed to this repo for review.
2. **Weekly Analytics Report — Fridays.** Performance from every connected channel committed as a report.
3. **Countdown Markers — Phase IV (Nov 2–6).** Daily 5·4·3·2·1 markers.
4. **The Doors Sequence — Nov 7.** Launch-day reveal package.

# Frontend & Design Resource List

Every link below was verified live (HTTP 200 or its canonical redirect)
on Sep 26, 2026. Organized by what the founder asked for: design language,
UI/UX, website making, visualization, creative effects, and managing it all.

## 1. Design language foundations (learn the grammar)
- https://github.com/tailwindlabs/tailwindcss — utility CSS; our canon colors/fonts map onto it
- https://github.com/shadcn-ui/ui — component canon; restrained institutional UI patterns
- https://github.com/radix-ui/primitives — accessible headless components (what shadcn builds on)
- https://github.com/material-components/material-components-web — Google Material; textbook for design tokens
- https://github.com/carbon-design-system/carbon — IBM's system; the best-documented design language in open source
- https://github.com/microsoft/fluentui — Microsoft's design language, fully open
- https://github.com/ant-design/ant-design — enterprise UI system, dense data tables
- https://github.com/chakra-ui/chakra-ui — component system with strong theming

## 2. UI engineering (making the website)
- https://github.com/react/react — React itself (moved to its own org; facebook/react redirects here)
- https://github.com/vercel/next.js — our stack
- https://github.com/vercel/commerce — production-grade storefront reference built on Next.js
- https://github.com/tailwindlabs/heroicons — clean icon set, matching restraint
- https://github.com/lucide-icons/lucide — the largest serious open icon library
- https://github.com/storybookjs/storybook — document and manage every component in isolation

## 3. Data visualization (leaderboards, dashboards)
- https://github.com/d3/d3 — the grammar of visualization; everything else is built on its ideas
- https://github.com/airbnb/visx — D3 power inside React components
- https://github.com/chartjs/Chart.js — fast, simple charts (what Base44 artifacts use)
- https://github.com/observablehq/plot — concise chart grammar
- https://github.com/plotly/plotly.js — scientific/financial-grade charts

## 4. Creative and motion (premium feel, done tastefully)
- https://github.com/mrdoob/three.js — real 3D in the browser
- https://github.com/pmndrs/react-three-fiber — Three.js as React components
- https://github.com/pmndrs/drei — helpers and effects for the above
- https://github.com/motiondivision/motion — motion library (Framer Motion's successor; framer/motion redirects here)
- https://github.com/greensock/GSAP — the professional animation standard
- https://github.com/processing/p5.js — creative coding; teaches visual thinking through code
- https://github.com/pixijs/pixijs — fast 2D WebGL graphics
- https://github.com/tsparticles/tsparticles — particles and backgrounds

## 5. Understanding visual design (study indices)
- https://github.com/terkelg/awesome-creative-coding — curated index: shaders, canvas, generative art
- https://github.com/alexpate/awesome-design-systems — index of design systems to study

## 6. Managing the work (quality gates, releases)
- https://github.com/changesets/changesets — versioned releases with changelogs
- https://github.com/semantic-release/semantic-release — fully automated releases
- https://github.com/typicode/husky — blocks bad commits before they land
- https://github.com/conventional-changelog/commitlint — enforces disciplined commit messages
- https://github.com/microsoft/playwright — end-to-end testing (clicks through the real site)
- https://github.com/eslint/eslint — code quality rules
- https://github.com/stylelint/stylelint — CSS/design quality rules

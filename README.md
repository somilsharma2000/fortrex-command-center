# FORTREX COMMAND CENTER

**WHERE TRADERS RISE.**

The central hub for FORTREX FX social media operations. This repo holds everything: brand assets, voice rules, content templates, calendars, and the master plan.

## Structure

- `brand-kit/` — the design law: colors, typography, materials, logo usage, voice rules
- `content-system/` — content pillars, caption formulas, hashtag banks, weekly calendar
- `templates/` — post format specs per platform (IG feed, stories, X, LinkedIn, YouTube)

## Brand Core

- Tagline: **WHERE TRADERS RISE.**
- Phase: Genesis Early Access
- Aesthetic: obsidian black, beveled gold, frosted glass, precision typography
- Voice: quiet confidence. Institutional. Never hype.

## Master Plan (4 Phases)

1. **Foundation** — brand kit locked, database schema (Posts, Media, Leads, Templates)
2. **Content engine** — caption + hashtag + visual generator, brand-filtered
3. **Calendar & pipeline** — weekly automated content batches, status tracking
4. **Analytics & Genesis backend** — performance tracking + working registration/referral system

## 2. Google Safe Browsing Compliance & Brand Voice Constraints

### Domain Flag Analysis (Sep 26 Incident Context)
The domain flag on Sep 26 occurred due to automated algorithmic scans detecting "prize/claim" wording commonly associated with financial sweepstakes and deceptive yield programs. ## 6. Day-One Anonymized Leaderboard Engine

### Dynamic Anonymization Framework
To combine competitive social proof with institutional privacy, every user receives a deterministic cryptographic handle upon registration (e.g., `TRADER-8092`, `ALGO-3041`, `QUANT-9182`). Public handles never display real names or email addresses.

### Transparent Ranking Scoring Formula
Waitlist rank is determined by a deterministic scoring formula calculated in real-time:

$$\text{Rank Score} = (V \times 100) + (R \times 50) + (P \times 25) - D$$

Where:
* $V$ = Verification Status ($1$ if email double opt-in completed, else $0$)
* $R$ = Number of Verified Referrals (capped at 50 max for scoring)
* $P$ = Precision Challenge / Cipher Completion Points
* $D$ = Decay Factor (applies if referral activity exhibits bot-like burst patterns)

### Zero-Manipulation Transparency Commitment
Unlike platforms that use synthetic phantom tickers or fake countdowns, FORTREX displays **strictly real data**:
* If 0 signups occur in an hour, the leaderboard remains static.
* All ranking calculations are logged to a public cryptographic hash log to prove zero artificial manipulation.

* **Operational Application:** Redact technical system specifications initially, revealing parameters progressively as community benchmarks are met.

* **Operational Application:** Provide instant value upon registration by delivering a high-quality PDF whitepaper on quantitative risk management.
